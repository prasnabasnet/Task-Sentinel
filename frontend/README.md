# TaskBoard Frontend

React + Vite UI for the Task Manager API. Jira-inspired board, backlog, and issue detail.

```bash
npm install
npm run dev
```

Requires the Django backend on `http://127.0.0.1:8000`. Vite proxies `/api` requests automatically.

Hover the small ⓘ icons next to buttons to see which API endpoint each action calls.
